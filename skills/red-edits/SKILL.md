# Red Edits — 수정한 부분은 빨간 글자로

Claude가 새로 쓰거나 바꾼 내용은 **모두 빨간색(#D00000)** 으로 표시해서, 사용자가 원본과 Claude의 작업을 한눈에 구분할 수 있게 한다.

## 규칙

1. **빨간색 대상**: Claude가 입력·추가·변경한 텍스트 전부 (빈칸 채우기, 문장 수정, 새 항목 추가).
2. **검정 유지**: 원래 있던 양식 라벨, 제목, 안내 문구, 사용자가 준 원문 중 바꾸지 않은 부분.
3. **삭제한 부분**: 지우지 말고 빨간 취소선으로 남긴다 (`<del>` / strike). 사용자가 "깔끔하게"를 원하면 생략 가능.
4. 문서 맨 위나 아래에 범례 한 줄을 넣는다: "※ 빨간 글자 = Claude 작성/수정 부분".
5. 최종 답변에서 무엇을 빨간색으로 표시했는지 짧게 요약한다.

## 형식별 적용법

| 형식 | 방법 |
|---|---|
| HTML | `<span class="edit">…</span>` + `.edit{color:#D00000}`, 삭제는 `<del class="edit">` |
| Markdown | `<span style="color:#D00000">…</span>` (렌더러가 HTML 허용 시) |
| DOCX | 해당 run에 `w:color w:val="D00000"` (python-docx: `run.font.color.rgb = RGBColor(0xD0,0,0)`) |
| XLSX | 수정 셀 `Font(color="FFD00000")` |
| HWP/HWPX | rhwp-edit/hwp 스킬로 삽입 후 글자색 빨강 지정, 불가하면 HTML 미리보기 병행 |
| 코드 | 색 지정 불가 → diff로 보여주고 변경 줄을 요약 |
